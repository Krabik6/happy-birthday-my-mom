# Карта твоего мира

Интерактивный подарок на день рождения: пиксельная карта вымышленного материка,
где каждое отмеченное место — черта характера, рассказанная через любимые книги
и сериалы. Когда открыты все семь мест, на южном мысу зажигается маяк с финальным
поздравлением.

Весь подарок — **один файл `index.html`**. Ни картинок, ни шрифтов, ни библиотек:
карта, сцены и даже шрифт рисуются кодом прямо в браузере. Работает офлайн,
открывается двойным кликом по файлу.

## Как это устроено для гостя

1. Заставка → кнопка «Развернуть карту».
2. Карта разворачивается сверху вниз, как свиток.
3. Клик по золотой метке открывает панель: пиксельная сцена, цитата, личная записка.
4. Открытые метки гаснут в контурные — видно, где ещё не был. Прогресс сохраняется.
5. 7 из 7 → зажигается маяк → финальный экран.

## Что менять под себя

Всё редактируемое собрано в одном месте — блок `CONFIG` в начале `<script>`:

```js
const CONFIG = {
  title:  'КАРТА ТВОЕГО МИРА',   // заголовок на заставке
  intro:  '...',                 // строка под заголовком
  finale: { title, text, quote, source },
  places: [ { id, name, kicker, x, y, scene, icon, quote, source, note }, ... ],
  lighthouse: { id, name, x, y }
};
```

Про поля:

- `name` — подпись на карте. Пишется **заглавными**: растровый шрифт знает
  кириллицу, цифры и знаки `. , ! ? : —`. Латиницы в нём нет.
- `note` — личная записка. Её и стоит переписать в первую очередь.
- `x`, `y` — положение метки в процентах от размера карты.
- `icon` — что нарисовать на карте: `ship`, `easel`, `tower`, `trees`, `castle`,
  `fire`, `peak`.
- `scene` — какая картинка откроется в панели: `sea`, `forest`, `mountain`,
  `library`, `castle`, `camp`, `atelier`, `lighthouse`.
- В `finale.text` пустая строка означает новый абзац.

Форма материка задаётся числом `SEED` — если поменять его, сгенерируется другая
карта. Метки при этом останутся на своих процентных координатах, а площадки под
ориентиры подстроятся сами.

## Темы

Карта рисуется в двух вариантах: ночная и дневная (пергамент). Это не инверсия
цветов, а один и тот же мир при разном свете. Вариант выбирается по системной
теме гостя.

## Проверить перед отправкой

Кнопка «Пройти заново» внизу карты сбрасывает прогресс — удобно, чтобы посмотреть
всё с начала своими глазами перед тем, как дарить.
